# 📰 News App (Flutter)

A modern **News Application** built with **Flutter**, focused on clean architecture, real-time data handling, and a smooth user experience.  
This project is designed to be a strong portfolio piece on GitHub.

---

## ✨ Features

- 🗞️ Browse latest news articles
- 📂 Categories (Business, Sports, etc.)
- 🔍 Search for news
- 🌙 Light & Dark Mode
- ⚡ Fast & responsive UI
- 🧱 Clean Architecture (Cubit / BLoC)
- 🌐 API integration

---

## 🛠️ Technologies Used

- **Flutter**
- **Dart**
- **Cubit (flutter_bloc)**
- **REST API**
- **HTTP**
- **Shared Preferences**
